**Goal:** Dar al portal público y al panel de la plantilla la estructura y el lenguaje visual del portal Peruano Canadiense, manteniendo el color, la tipografía y el contenido elegibles por la institución.

**Architecture:** El portal público se pinta con bloques (`render-bloque.ts` → HTML escapado) dentro del marco (`marco-portal.ts`); el estilo vive en `styles/_tokens|_fuentes|_marco|_componentes.scss` y los colores llegan como custom properties desde `temaPublico()`. El rediseño reestiliza esas capas, añade 2 bloques al catálogo (`cms/blocks.json` → `tools/generar-bloques.py`), 3 claves de Apariencia (API + panel), un carrusel accesible y el reestilo del `AdminShell`, el login y el editor.

**Tech Stack:** Angular 21 standalone + signals, SCSS, Vitest + jsdom, PHP 8.1 sin framework, MariaDB, Python 3 (herramientas).

**Spec:** `docs/superpowers/specs/2026-11-21-diseno-pc-design.md` · Referencia visual: `referencia-diseno-pcanadiense/` (`DISENO.md`, `GUIA-ADAPTACION-INDECOPI.md`, `capturas/`, `codigo/`).

## Global Constraints

- Angular 21 y PHP 8.1. **Sin dependencias npm ni Composer nuevas. Sin CDN de terceros** (fuentes e iconos autohospedados).
- **Ningún hex de marca en SCSS/TS de UI.** Solo `var(--color-*)`; derivados con `color-mix(in srgb, …)` usados en propiedades normales, nunca dentro de la definición de otra custom property (ver comentario de `--color-lavado` en `core/tema.ts`). Excepciones permitidas: `#fff`/`#000`/`transparent` en sombras y velos, y el verde de plataforma WhatsApp `#25d366`.
- Texto sobre fondos de color: sobre `--color-primario` usar `--color-boton-texto`; sobre `--color-primario-fuerte` usar `--color-boton-texto-hover`; sobre `--color-acento-relleno` usar `--color-sobre-acento` (Tarea 1). Así el contraste ≥4.5:1 lo garantiza `temaPublico()` para cualquier color elegido.
- Todo texto visible en **español neutro**. Comentarios en español explicando el porqué (estilo actual del repo).
- No romper claves de contrato: `slug`, `version`, `contenido`, `items`. Los campos nuevos de bloques son opcionales y con `defaults`.
- Todo HTML de bloques sale escapado (`escapeHtml`/`escapeAttr`); todo enlace pasa por `hrefValido()` (bloques) o `urlSegura()` (marco/apariencia).
- `prefers-reduced-motion: reduce` anula transiciones/animaciones nuevas; foco visible en todo control; carrusel automático con botón de pausa.
- No hay git en la carpeta de entrega: al final de cada tarea anotar la verificación en la sección «Registro de ejecución» al final de este archivo (si se inicializa git, un commit por tarea).
- Comandos de verificación (desde `frontend/`): `npx vitest run --config vitest.config.ts`, `npx tsc -p tsconfig.app.json --noEmit`, `npm run build`. API: ver README (`docker exec plantilla_portal_api php /app/API/pruebas/ejecutar.php`). Línea base: **25 archivos / 125 pruebas en verde**.
- Tras editar `cms/blocks.json` ejecutar siempre `python3 tools/generar-bloques.py` (regenera `API/cms/blocks.json` y `frontend/src/app/cms/block-catalog.generated.ts`; no editarlos a mano).

```python
ROOT = Path(__file__).resolve().parents[1]

for nombre, lucide in MAPA.items():
    svg = urllib.request.urlopen(f'https://unpkg.com/lucide-static@{VERSION}/icons/{lucide}.svg').read().decode()
    cuerpo = re.search(r'<svg[^>]*>(.*)</svg>', svg, re.S).group(1).strip()

        f'stroke-width="2" stroke-linecap="round" stroke-linejoin="round">{cuerpo}</symbol>')
destino = ROOT / 'frontend' / 'public' / 'iconos.svg'
destino.write_text('<svg xmlns="http://www.w3.org/2000/svg" style="display:none">\n'
                   f'<!-- Lucide {VERSION}, licencia ISC. Generado por tools/generar-iconos.py -->\n'
                   + '\n'.join(simbolos) + '\n</svg>\n', encoding='utf-8')
print('Wrote', destino, len(simbolos), 'iconos')
```

```ts
/** Botón con clase propia; sin enlace navegable se degrada a texto. */
function renderBoton(etiquetaBoton: string, href: unknown, clase: string): string {
  if (!etiquetaBoton.trim()) {
    return '';
  }
  if (!hrefValido(href)) {
    return `<p>${escapeHtml(etiquetaBoton)}</p>`;
  }
  return `<a class="${clase}" href="${escapeAttr(href.trim())}">${escapeHtml(etiquetaBoton)}</a>`;
}
```

```ts
/**
 * Carrusel del banner de portada. El HTML lo genera el renderizador como
 * cadena, así que el comportamiento se engancha después, sobre el DOM.
 * Cumple WCAG 2.2.2: todo lo que se mueve solo se puede pausar, y con
 * «reducir movimiento» arranca pausado.
 */
export const INTERVALO_HERO = 6000;

export function iniciarCarrusel(hero: HTMLElement, intervalo = INTERVALO_HERO): () => void {
  const slides = Array.from(hero.querySelectorAll<HTMLElement>('.hero__slide'));
  const puntos = Array.from(hero.querySelectorAll<HTMLButtonElement>('.hero__punto'));
  const pausa = hero.querySelector<HTMLButtonElement>('.hero__pausa');
  if (slides.length < 2) {
    return () => {};
  }
  let actual = 0;
  let pausado = window.matchMedia?.('(prefers-reduced-motion: reduce)').matches ?? false;
  let temporizador: ReturnType<typeof setInterval> | undefined;

  const mostrar = (i: number): void => {
    actual = (i + slides.length) % slides.length;
    slides.forEach((s, k) => {
      const visible = k === actual;
      s.classList.toggle('hero__slide--activa', visible);
      s.toggleAttribute('inert', !visible);
      if (visible) s.removeAttribute('aria-hidden');
      else s.setAttribute('aria-hidden', 'true');
    });
    puntos.forEach((p, k) => p.setAttribute('aria-current', String(k === actual)));
  };
  const detener = (): void => {
    clearInterval(temporizador);
    temporizador = undefined;
  };
  const arrancar = (): void => {
    detener();
    if (!pausado) temporizador = setInterval(() => mostrar(actual + 1), intervalo);
  };
  const pintarPausa = (): void => {
    pausa?.setAttribute('aria-pressed', String(pausado));
    pausa?.setAttribute('aria-label', pausado ? 'Reanudar carrusel' : 'Pausar carrusel');
  };
  const alPausar = (): void => {
    pausado = !pausado;
    pintarPausa();
    arrancar();
  };
  const alElegir = (e: Event): void => {
    mostrar(puntos.indexOf(e.currentTarget as HTMLButtonElement));
    arrancar();
  };

  pausa?.addEventListener('click', alPausar);
  puntos.forEach((p) => p.addEventListener('click', alElegir));
  // Mientras el visitante lee o usa el teclado dentro del banner, no cambia.
  hero.addEventListener('mouseenter', detener);
  hero.addEventListener('mouseleave', arrancar);
  hero.addEventListener('focusin', detener);
  hero.addEventListener('focusout', arrancar);
  pintarPausa();
  arrancar();

  return () => {
    detener();
    pausa?.removeEventListener('click', alPausar);
    puntos.forEach((p) => p.removeEventListener('click', alElegir));
    hero.removeEventListener('mouseenter', detener);
    hero.removeEventListener('mouseleave', arrancar);
    hero.removeEventListener('focusin', detener);
    hero.removeEventListener('focusout', arrancar);
  };
}

/** Lleva la cuenta de los carruseles vivos de una página: inicia los nuevos y limpia los que ya no están. */
export class Carruseles {
  private readonly activos = new Map<HTMLElement, () => void>();

  constructor(private readonly intervalo = INTERVALO_HERO) {}

  sincronizar(raiz: HTMLElement): void {
    for (const [hero, detener] of this.activos) {
      if (!hero.isConnected) {
        detener();
        this.activos.delete(hero);
      }
    }
    raiz.querySelectorAll<HTMLElement>('.hero[data-carrusel]').forEach((hero) => {
      if (!this.activos.has(hero)) this.activos.set(hero, iniciarCarrusel(hero, this.intervalo));
    });
  }

  detenerTodo(): void {
    this.activos.forEach((detener) => detener());
    this.activos.clear();
  }
}
```

```php
function camposNoticia(array $datos, ?array $actual, array $usuario): array
```

```ts
import { HttpClient } from '@angular/common/http';

const acotar = (v: unknown, min: number, max: number, defecto: number): number => {
  const n = Number(v);
  return Number.isFinite(n) ? Math.max(min, Math.min(max, Math.trunc(n))) : defecto;
};

        <p class="novedades__vacio">Pronto publicaremos novedades.</p>
      } @else {
        <div class="novedades__rejilla">
          @if (destacada(); as d) {
            <section class="novedades__panel" aria-label="Noticias">
              <div class="novedades__noticias">

  readonly bloque = input<JsonMap>({});

  readonly comunicados = signal<NoticiaPublica[]>([]);
  readonly cargado = signal(false);

  readonly destacada = computed(() => this.noticias().find((x) => x.destacada) ?? this.noticias()[0] ?? null);
  readonly resto = computed(() => this.noticias().filter((x) => x !== this.destacada()));

  private readonly formato = new Intl.DateTimeFormat('es-PE', { day: 'numeric', month: 'long', year: 'numeric' });

  constructor() {
    effect(() => {
      const props = this.bloque();
      const cn = acotar(props['cantidadNoticias'], 1, 6, 4);
      const cc = acotar(props['cantidadComunicados'], 0, 6, 3);
      void this.cargar(cn, cc);

    return typeof v === 'string' ? v.trim() : '';

    return Number.isNaN(d.getTime()) ? '' : this.formato.format(d);

    this.noticias.set(noticias);
    this.comunicados.set(comunicados);
    this.cargado.set(true);
  }
```

```ts
export type Ajuste = 'texto-grande' | 'alto-contraste' | 'resaltar-enlaces' | 'sin-animaciones' | 'fuente-legible' | 'espaciado';

const AJUSTES: { id: Ajuste; nombre: string }[] = [
  { id: 'texto-grande', nombre: 'Texto más grande' },
  { id: 'alto-contraste', nombre: 'Alto contraste' },
  { id: 'resaltar-enlaces', nombre: 'Resaltar enlaces' },
  { id: 'sin-animaciones', nombre: 'Detener animaciones' },
  { id: 'fuente-legible', nombre: 'Fuente más legible' },
  { id: 'espaciado', nombre: 'Más espacio entre líneas' },
];
const CLAVE = 'pa-ajustes';

/**
 * Ajustes de lectura del visitante. Cada ajuste es una clase en <html>, así
 * se aplica a todo el sitio sin que cada componente lo conozca, y se recuerda

@Component({
  selector: 'app-panel-accesibilidad',
  standalone: true,

  changeDetection: ChangeDetectionStrategy.OnPush,
  template: `

      aria-controls="pa-dialogo" [attr.aria-expanded]="abierto()" (click)="abierto.set(!abierto())">
      <app-icono nombre="accesibilidad" />
    </button>

          @for (a of ajustes; track a.id) {

  readonly ajustes = AJUSTES;
  readonly abierto = signal(false);
  readonly activos = signal<Ajuste[]>(leerGuardados());

  constructor() {
    effect(() => {
      const raiz = document.documentElement;
      for (const a of AJUSTES) raiz.classList.toggle(`pa-${a.id}`, this.activos().includes(a.id));
      try {
        localStorage.setItem(CLAVE, JSON.stringify(this.activos()));

        // Sin almacenamiento (modo privado): el ajuste vale para esta visita.

    this.activos.set([]);
  }

  @HostListener('document:keydown.escape')
  cerrar(): void {
    this.abierto.set(false);
  }
}

function leerGuardados(): Ajuste[] {
  try {
    const guardado: unknown = JSON.parse(localStorage.getItem(CLAVE) ?? '[]');
    return Array.isArray(guardado) ? guardado.filter((x): x is Ajuste => AJUSTES.some((a) => a.id === x)) : [];
  } catch {
    return [];
  }
}
```

### Qué se adaptó mejor que el original

- **Contraste garantizado, no aproximado**: PC pinta blanco sobre naranja (~2.9:1, bajo AA). Aquí `temaPublico()` elige blanco/negro sobre el acento y ajusta el acento-texto a ≥4.5:1 para cualquier color que elija la institución; las 5 paletas del panel corrigen los tonos de PC que no llegaban a 4.5.
- **Todo editable**: lo que en PC es código fijo (accesos de la franja, CTA de cabecera, número de WhatsApp, iconos) aquí son datos de Apariencia o props de bloque.
- **Noticias con flujo editorial real**: borrador/publicado con roles, fecha de publicación, slug único, saneado de cuerpo, índice de búsqueda y sitemap sincronizados en cada guardado.

- **Sin dependencias**: cero paquetes npm/Composer nuevos y cero CDN (fuentes e iconos autohospedados).

### Riesgos y notas de despliegue

- **Sin `environment.prod`**: la API se sirve same-origin en `/api` (el `.htaccess` del build la enruta a `API/entrada.php`); solo hace falta `globalThis.__API_URL__` si el API viviera en otra ruta. No hay flag que voltear.
- **Fuentes y sprite**: `frontend/public/fonts/poppins-*.woff2` e `iconos.svg` se copian al `dist` automáticamente (verificado en el build); subir `dist/.../browser/` completo.
- **Migración de noticias**: en bases existentes, reimportar `API/esquema.sql` (idempotente: crea `noticias` sin tocar datos) y luego `tools/reindexar-busqueda.php` una vez. El módulo ya mantiene el índice por noticia.
- **Seeder demo**: `tools/sembrar-demo.py` siembra la portada con la secuencia PC y 4 noticias de muestra; es idempotente pero es contenido de demostración — revisar antes de entregar a producción.
- **Hero sobre fotos**: el texto lleva veladura degradada del primario-fuerte (88 %→0) + sombra de texto; con fotos muy claras el borde derecho del subtítulo puede quedar bajo. Es la misma aproximación del diseño origen; conviene fotos con zona oscura a la izquierda.
- **Ratelimit de login**: 8 intentos/5 min por IP (archivos en `API/tmp/ratelimit/`, gitignored); en pruebas de captura repetidas puede saltar — esperar 5 min o borrar el JSON.
- **Capturas con reveal**: para pantallas completas hay que esperar en el pie ~1.5 s antes de capturar (IntersectionObserver); si no, los bloques bajo el pliegue salen transparentes en la imagen, no en el uso real.
